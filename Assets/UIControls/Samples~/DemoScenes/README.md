# UIControls Demo Scenes (Samples)

This sample contains two ready-to-run scenes:

- `Scenes/UIControlsDemo.unity` - base controls demo (`UIButtonControl`, `UIToggleControl`, `UIProgressBarControl`).
- `Scenes/UIProgressBarDemo.unity` - advanced progress bar scenarios (`HitBar`, segmented energy charge, spend super action).

## How to use

1. Open `Window > Package Manager`.
2. Select `UIControls (uGUI + DOTween)`.
3. In the `Samples` section import `Demo Scenes`.
4. Open one of the scenes from `Assets/Samples/UIControls (uGUI + DOTween)/<version>/Demo Scenes/Scenes`.

## Notes

- Sample scenes use assets included in this sample package (`Art/Slider`).
- Ensure DOTween is installed and initialized in the target project.
