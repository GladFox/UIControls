# Product Context

## Цель
Создать библиотеку UI-контролов на базе Unity `uGUI` с анимациями через `DOTween`.

## Продуктовые принципы
- Переиспользуемые контролы с единым подходом к анимации.
- Предсказуемое состояние и явный API для вызова из кода.
- Минимальная связность между контролами.
- Внешние UI-решения используются только как источник идей, но не как runtime-зависимость.

## Текущий фокус
- Широкий каталог контролов (~50 шт.) по категориям A–I поверх базового слоя
  (`Button`, `Toggle`, `Modal`, `ProgressBar`, `TabSlider`). Пакет `0.20.0`.
- Каждый контрол поставляется с запускаемой демо-сценой и editor-билдером; сцены
  сгруппированы по папкам категорий (`Selection(A)`…`Data(I)`).
- Demo-логика — в презентерах через сериализуемые ссылки; UI-структура не создаётся в runtime
  (исключение — рантайм-спрайты/текстуры у визуальных контролов).
- Переиспользуемые `ScriptableObject`-пресеты состояний и расширяемые SO-действия сохранены как
  фундамент кастомизации.

## Категории
- A — selection/sliders, B — overlays, C — scrolling, D — input, E — feedback/decoration,
  F — gameplay, G — navigation, H — forms, I — data/overlays.
